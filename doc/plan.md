# 端到端图像生成与血管分割 — 实验计划 (已定稿)

## 一、任务回顾

| 项目 | 内容 |
|------|------|
| 输入 | 3D NCCT 影像 |
| 输出1 | 合成 CTA 影像（图像生成） |
| 输出2 | 血管分割 Mask（分割） |
| 数据量 | 100 例已配准的 NCCT/CTA/SEG |
| 划分 | 训练 70 / 验证 10 / 测试 20（对外 4:1） |
| 生成评价 | PSNR、SSIM |
| 分割评价 | Dice、IoU、Accuracy |
| 提交物 | 实验报告 + 测试集分割结果 + 源代码 |

## 二、技术方案（已确定）

### 2.1 核心思路

**多任务 U-Net + 2D 轴向切片训练**。

- 将 3D 体积沿轴向切为 2D 切片训练，推理时逐切片预测后堆叠还原
- 共享编码器 + 双解码器（CTA 生成 / 血管分割）

### 2.2 可选方案决策记录

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 切片方向 | 仅轴向 (axial) | 标准做法，横截面血管结构清晰；冠状/矢状增加复杂度但收益有限 |
| 2D vs 3D | 2D 切片 | 数据量扩充(100→数万)，训练快，参考报告验证可行；3D patch 过于复杂 |
| 图像尺寸 | 256×256 | 参考报告同尺寸，平衡细节与显存；如原始数据差异大则调整 |
| 损失权重 | λ1=λ2=0.5 | 两任务同等重要；如分割欠佳可调至 segmentation 权重 0.7 |
| 额外参考文献 | 不需要 | 参考报告已提供足够范式，先完成 baseline |
| 数据增强 | 基础增强(翻转+旋转) | 弹性变形等强增强留作后续优化空间 |

### 2.3 数据划分

```
100 例
├── 训练集: 70 例 (70%)  ← 梯度更新
├── 验证集: 10 例 (10%)  ← 早停 + 调参
└── 测试集: 20 例 (20%)  ← 最终评估，只测一次
        ↑
        └── 对外 4:1 (训练含验证 : 测试 = 80:20)
```

固定随机种子 seed=42，按 patient ID 划分，确保可复现。

### 2.4 模型架构

```
         NCCT (1 x 256 x 256)
              │
      ┌───────▼───────┐
      │ Shared Encoder │  (64→128→256→512)
      │  (U-Net downs) │
      └───────┬───────┘
              │
      ┌───────┴───────┐
      │   Bottleneck   │  (1024)
      └───────┬───────┘
              │
    ┌─────────┴─────────┐
    ▼                   ▼
┌───────────┐     ┌───────────┐
│ CTA Decoder│    │ SEG Decoder│
└─────┬─────┘     └─────┬─────┘
      ▼                   ▼
  Synthetic CTA       Vessel Mask
   (Tanh out)          (Sigmoid out)
```

### 2.5 损失函数

`Loss = 0.5 * L1(CTA_pred, CTA_gt) + 0.5 * BCE(SEG_pred, SEG_gt)`

### 2.6 评价指标

| 任务 | 指标 |
|------|------|
| CTA 生成 | PSNR, SSIM |
| 血管分割 | Dice, IoU, Accuracy |
