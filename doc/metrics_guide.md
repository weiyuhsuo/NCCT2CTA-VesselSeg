# 评价指标直观理解

> 人话解释，帮你 build intuition。代码实现在 `src/metrics.py`。

---

## Dice Coefficient（血管分割）

**一句话**：预测的血管 mask 和真实 mask 有多"重合"。

**公式本质**：`2 × 交集面积 / (预测面积 + 真实面积)`

想象你画了一个圈，老师画了一个圈：
- 两个圈完全重叠 → Dice = **1.0**（完美）
- 两个圈完全不挨着 → Dice = **0.0**（完全错误）
- 两个圈有一半重叠 → Dice ≈ **0.5**

**Dice 水平对照**（医学图像分割经验值）：

| Dice | 什么水平 | 能干嘛 |
|------|:------:|--------|
| < 0.5 | 不能用 | 模型基本在瞎猜 |
| 0.5~0.7 | 勉强 | 大概位置对，边界糊，细结构丢 |
| 0.7~0.8 | 及格 | 临床辅助参考级别 |
| 0.8~0.9 | 好 | 多数病例可靠，可辅助诊断 |
| 0.9~0.95 | 优秀 | 接近人工标注水平 |
| > 0.95 | 天花板 | 基本跟标注者画的一样 |

**为什么 Dice 比 Accuracy 重要**：血管只占图像 ~2%。如果模型把所有像素预测成"背景"，Accuracy = 98%，但 Dice = 0。**Accuracy 骗人，Dice 不骗人。**

---

## IoU / Jaccard（血管分割）

**一句话**：比 Dice 更严格的"重合度"指标。

**区别**：
- Dice 分母 = （你的面积 + 老师的面积）÷ 2
- IoU 分母 = 你+老师合起来的总面积（并集）
- **IoU 永远 ≤ Dice**，同样的结果 IoU 分数更低

比如半重叠：Dice = 0.5，IoU ≈ 0.33

**Dice <-> IoU 经验映射**：

| Dice | 大概对应 IoU |
|------|:----------:|
| 0.5 | ~0.33 |
| 0.7 | ~0.54 |
| 0.8 | ~0.67 |
| 0.9 | ~0.82 |

---

## PSNR（CTA 图像生成质量）

**一句话**：生成的 CTA 和真实的 CTA 像素值差多少。**越大越像。**

把两幅图每个像素的差值平方平均 → 差值越小 PSNR 越高。

| PSNR (dB) | 什么水平 | 肉眼感觉 |
|-----------|:------:|---------|
| < 20 | 很差 | 明显噪声/伪影 |
| 20~25 | 凑合 | 看得出个大概 |
| 25~30 | 还行 | 远看像，近看有差异 |
| 30~35 | 好 | 仔细对比才能看出 |
| 35~40 | 优秀 | 几乎看不出 |
| > 40 | 天花板 | 噪声比信号还小 |

**PSNR 的盲区**：两幅图平移 1 像素，人眼看几乎一样，PSNR 暴跌。所以需要配合 SSIM。

---

## SSIM（CTA 图像结构相似度）

**一句话**：生成的 CTA 和真实的 CTA "结构像不像"。**越大越像。**

把图像切成一堆小窗口，每个窗口比三样东西：
1. 平均亮度差多少
2. 对比度差多少
3. 纹理/结构差多少

三个维度加权 → 0~1 的分数。

| SSIM | 什么水平 | 直观感受 |
|------|:------:|---------|
| < 0.5 | 差 | 结构完全不对 |
| 0.5~0.8 | 勉强 | 大致形状对，细节乱 |
| 0.8~0.9 | 还行 | 结构基本正确 |
| 0.9~0.95 | 好 | 肉眼难辨真假 |
| > 0.95 | 优秀 | 几乎完美 |

**PSNR vs SSIM 最直观区别**：
- PSNR = 逐像素比，"这个点的灰度值差了 5"
- SSIM = 逐区域比，"血管走向对不对、粗细对不对"
- **PSNR 低 + SSIM 高** = 结构对但像素值有偏差（**Round 1 就是这样**：SSIM 0.91 达标，PSNR 24.9 偏低——结构学会了，细节不够锐利）

---

## 2D Dice vs 3D Dice（为什么差这么多）

Round 1：2D Dice = 0.52，3D Dice = 0.79

原因：
- 2D Dice 在 256×256 切片上直接比 → 细血管被压缩没了
- 3D Dice：256→推理→概率图 resize 回 512→二值化 → **细血管被救回来**

类比：模糊的眼镜看视力表看不清，拿远一点反而能猜对。但最好换个高清眼镜——Round 2 改成 512×512 训练做的是这件事。

---

## Accuracy（别被骗了）

模型全预测"没血管" → Accuracy = 98%
模型精准分割 → Accuracy = 99.8%

看起来像进步了 2%，实际上是从"全错"到"全对"。**类别极度不平衡时，Accuracy 是摆设。**

## 速查表

| 指标 | 范围 | 越大越好 | 测什么 | 怕不平衡? |
|------|:----:|:--------:|--------|:--------:|
| Dice | [0,1] | 是 | 分割重合度 | 不怕 |
| IoU | [0,1] | 是 | 分割重合度(更严) | 不怕 |
| PSNR | [0,inf) | 是 | 像素值误差 | 不怕 |
| SSIM | [0,1] | 是 | 结构相似度 | 不怕 |
| Accuracy | [0,1] | 是 | 逐像素正确率 | **严重受影响** |
